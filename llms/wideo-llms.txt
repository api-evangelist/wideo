# Wideo

> Wideo is an online video creation and automation platform. Its Video Automation API renders finished MP4 videos at scale from reusable templates and structured per-video data, with asynchronous batch rendering, webhook completion callbacks, and signed video/preview URLs.

## APIs

- [Wideo Video Automation API — Documentation](https://wideo.co/api-documentation/): Create rendering batches from a template and per-video variables; poll batch status for signed asset URLs. Auth: x-api-key header.
- [Video API product overview](https://wideo.co/api/): Automated video creation at scale from any data source.
