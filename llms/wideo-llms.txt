# Wideo

> Wideo is an online video creation and automation platform. Its Video Automation API renders finished MP4 videos at scale from reusable templates and structured per-video data, with asynchronous batch rendering, webhook completion callbacks, and signed video/preview URLs. API access is not self-serve — every tier is entered through a "Request API access" form — and Wideo publishes no OpenAPI, no SDK, and no MCP server.

## APIs

- [Wideo Video Automation Batch API](https://wideo.co/api-documentation/): POST /batch creates a rendering batch from a template and per-video variables and returns a batchId; GET /batch/{batchId} returns status and signed asset URLs. Base https://automationapi.wideo.co. Auth: x-api-key header (UUID).
- [Wideo legacy Automation API](https://wideo.co/api/): POST /automation/replace substitutes template variables and returns a REPLACE_OBJECT_ID; POST /automation/encode renders it into an MP4. Same base host.

## Notes for agents

- There is no MCP server and no A2A agent card. Every /.well-known/ path returns 404 on wideo.co and 403 on automationapi.wideo.co.
- Rendering is asynchronous. create_batch returns a batchId, not a video. SUCCEEDED is the only terminal status Wideo publishes, so there is no documented failure exit from a poll loop.
- No idempotency key exists. Resubmitting a batch renders and bills it again.
- Consumption is billed in credits: 1 credit = 60 seconds of generated video, on a monthly allowance (Basic 500 / Pro 1,000 / Pro+ 2,000 / Enterprise custom).
- Errors are a bare {"message": "..."} envelope from AWS API Gateway; the failure class is in the x-amzn-errortype header.
